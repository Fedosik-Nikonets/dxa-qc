# Финальная сдача: комплект и порядок действий

Что входит в финальную сдачу по ТЗ 7.2, откуда это берётся и что сделать
27–29 сентября. Проверка на закрытых данных идёт без участия команды,
поэтому образ и инструкция должны работать «как есть».

Команда организатора для проверки — одна строка из README:

```bash
docker load < dxa-qc_1.1.0.tar.gz
./run.sh <каталог или zip с исследованиями> <каталог результатов>
```

## Порядок действий

**27 сентября, до 18:00 — заморозка.**

1. Пересчитать отчёты в закреплённом окружении и закоммитить:
   ```bash
   ./scripts/refresh_reports.sh
   git add reports
   git commit -m "Отчёты пересчитаны перед заморозкой"
   ```
   Скрипт сам остановится, если хоть одно решение на обучающем наборе
   разошлось с прежним эталоном.
2. `git push origin main`.
3. Полная проверка «как на чистой машине» (10–20 минут: образ amd64
   собирается через эмуляцию):
   ```bash
   ./scripts/freeze_check.sh
   ```
   В итоге все строки — `OK`, предупреждений о незакоммиченном и
   неотправленном нет. Записать sha256 файла образа из итога.
4. Поставить тег и отправить его:
   ```bash
   git tag -a v1.1.0 -m "Финальная сдача"
   git push origin v1.1.0
   ```

**28–29 сентября — только критические правки.** Любая правка — новый
коммит, `./scripts/freeze_check.sh`, новый тег `v1.0.1` и новый файл образа.

**Отправка — форма в личном кабинете, до 29 сентября 23:59 МСК.**

| поле формы | что вставить |
|---|---|
| Репозиторий | публичный репозиторий без `Data/` и без истории с данными; `README.md` в корне с запуском локально |
| Документация | ссылка на `README.md` (из него — ссылки на `docs/user_guide.md`, `docs/deployment.md`, `docs/training.md`) |
| Презентация | PDF на облачном диске: экспорт `presentation/DXA_QC_presentation.pptx` из PowerPoint с установленным шрифтом Montserrat |
| Прототип | скринкаст сценария `docs/demo_scenario.md` (Swagger `/docs`, веб-интерфейс, overlay) на облачном диске |
| Дополнительные материалы | папка на облачном диске: `dxa-qc_1.1.0.tar.gz`, `dxa-qc_1.1.0_src.zip`, их sha256, PDF презентации |

Все ссылки — с доступом «Просматривать могут все, у кого есть ссылка»;
проверить в окне инкогнито. После 23:59 29 сентября в отправленные ветки,
документы и файлы по ссылкам ничего не вносим — иначе дисквалификация.

```bash
git archive --format=zip -o dxa-qc_1.1.0_src.zip HEAD -- . ':(exclude)Data'
shasum -a 256 dxa-qc_1.1.0.tar.gz dxa-qc_1.1.0_src.zip
```

* `dxa-qc_1.1.0.tar.gz` — образ (около 130 МБ);
* `dxa-qc_1.1.0_src.zip` — исходный код, документация, отчёты и
  презентация (без данных организатора из `Data/`);

Старый файл `dxa-qc_0.2.0.tar.gz` (сборка 23 сентября) после сборки 1.1.0
удалить, чтобы не отправить по ошибке.
