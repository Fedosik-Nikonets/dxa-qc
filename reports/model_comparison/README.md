## Что на слайде

**Слева** — F1 «есть нарушение» по всем 249 размеченным изображениям,
честно: пороги и выбор только на обучающих фолдах `split.csv`, ДИ 95% —
бутстреп по исследованиям. Точка с интервалом, а не столбец: ось
начинается с 0.35, столбцы бы преувеличили разницу.

| вариант | F1 [ДИ 95%] |
|---|---|
| всё — нарушение (тривиальная база) | 0.45 [0.41; 0.50] |
| классификатор по пикселям снимка | 0.48 [0.40; 0.55] |
| правила без ротации | 0.50 [0.40; 0.61] |
| гибрид: геометрия + пиксели снимка | 0.51 [0.42; 0.59] |
| обучаемая голова на геометрии | 0.56 [0.48; 0.64] |
| правила + ротация в точке локализатора v2 — отклонена | 0.56 [0.48; 0.64] |
| **правила + ротация по профилю края — в сервисе** | **0.60 [0.51; 0.68]** |
| правила + ResNet18 на области вертела — эксперимент | 0.63 [0.53; 0.71] |

Парные разности (тот же бутстреп по исследованиям):
* сервис минус «всё — нарушение»: **+0.14 [+0.05; +0.24]** — ДИ не касается
  нуля, сервис лучше тривиального ответа не случайно;
* ResNet18 минус сервис: +0.03 [−0.04; +0.10] — в пределах шума;
* ротация v2 минус сервис: −0.04 [−0.12; +0.04].

**Справа** — варианты по задачам. Артефакты (17 позитивов, 20 повторов
стратифицированной проверки): один признак top-hat 0.70 против 0.01 у HOG на
144 признаках — обучаемому классификатору не на чем учиться. Ротация (36
позитивов): профиль медиального края 0.48 вложенно; угол + заполненность маски
0.49 (OOF) отклонён — заполненность мерит плотность кости, то есть то, ради
чего исследование и делается, а не укладку; ResNet18 на всём снимке 0.36, на
области вертела 0.50; профиль в точке локализатора v2 0.43 вложенно —
отклонён по критерию, закоммиченному до проверки (F1 ≥ 0.53).

**Локализация малого вертела** (ТЗ 8.4, «расстояние между ключевыми
точками»; `localization.csv`, 58 точек врача):

| вариант | медиана, мм | p90, мм | ≤ 5 мм |
|---|---|---|---|
| якорь v1 — точка на overlay сервиса | 9.0 | 25.2 | 26% |
| локализатор v2, OOF — не включён | 2.5 | 18.8 | 84% |

## Что говорить

1. Сравнивали на одних фолдах и одной мере — честной, с интервалами.
2. Обучаемые модели на 6–36 позитивах на метку правилам не выигрывают:
   ранжируют прилично, но выбор порога на таком числе позитивов съедает
   преимущество. Правила при этом объяснимы и видны на overlay.
3. Сервис лучше «всё — нарушение» с ДИ, не касающимся нуля; без ротации
   этого не было бы (бедро было бы ниже тривиальной базы).
4. ResNet18 на области вертела — лучшая точка, но разница с сервисом в
   пределах шума, область выбрана после первого эксперимента, а в образ
   пришлось бы тянуть torch.
5. Точная точка — ещё не точное решение. Локализатор v2 ставит вертел в
   3.7 раза точнее (медиана 9.0 → 2.5 мм), но правило ротации в этой
   точке хуже (0.43 против 0.48). Критерий включения мы зафиксировали в
   git до проверки — и v2 не включили. Направление развития: ResNet18 на
   области вокруг точки локализатора v2 — у обоих кусков уже есть честные
   цифры по отдельности.
