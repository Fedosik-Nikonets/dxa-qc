## 1. Правило ротации

**Заморозка.** `scripts/17_fit_rotation_rule.py` применяет ко всем 150
изображениям ту же процедуру, что вложенная проверка напарника применяла к
каждому обучающему набору: признак выбирается из четырёх по F1 при
специфичности ≥ 0.75 на пяти фолдах, границы двух хвостов — по F1 при
той же специфичности. Метрики выбора совпали с `candidate_metrics.csv`
скрипта 14 построчно (скрипт это проверяет).

| признак | F1 (5 фолдов) | специф. |
|---|---|---|
| **bump_mm** | **0.506** | 0.798 |
| profile_contrast | 0.500 | 0.763 |
| profile_intensity | 0.389 | 0.807 |
| anchor_intensity | 0.232 | 0.781 |

Выбран `bump_mm` — высота локального выступа медиального края в окне
малого вертела, норма **[−0.19; 0.66] мм**. Во вложенной проверке четыре
фолда из пяти выбрали `profile_contrast`: 0.506 против 0.500 — монетка,
это сказано в README п. 8. Модель — `models/rotation_profile_v1.json`
(1.2 КБ, с версией признаков, правилом выбора, честной оценкой и хэшами
входов).

**Встраивание.** `src/dxa_qc/rotation_rule.py`, вызывается из
`batch.predict` для бедра. Отказ (край не прослеживается) нарушения не
ставит, причина — в диагностике `rotation_reason`. Без файла модели
проверка пропускается, как у детектора артефактов.

**Сверка.** Признаки, посчитанные конвейером, совпадают с
`reports/rotation_human_profile/features.csv` до 6·10⁻¹⁵ на всех 150
кадрах; решения совпадают все 150; ближайшее значение от границы —
1·10⁻³ мм. Полный прогон 499 файлов: 0 Failure, нарушения ротации на 97
строках; все прочие решения совпадают с прогоном до правки построчно.

## 3. Overlay-серия

`python -m dxa_qc.batch ... --overlays overlays.zip` — PNG на каждый файл
(`<path_to_study>.png`), модуль `src/dxa_qc/overlay.py`. Пример —
`reports/overlay_examples.png`.

| область | что нарисовано |
|---|---|
| позвоночник | контур маски; главная ось и вертикаль; граница нижней полосы для укладки; карта отклика top-hat — только при найденном артефакте |
| бедро | контур маски; рамка поля сканирования и его длина; прослеженный медиальный край, окно поиска и точка выступа малого вертела |

Красное — сработавшее правило. Подписи латиницей (шрифт OpenCV без
кириллицы). Карта — отклик признака, а не Grad-CAM: CNN в решении нет.
Для этого `artifact.features` разделён на `_response` + `tophat_map`, чтобы
карта и признак считались одной функцией; признаки на 499 файлах не
изменились.

Свойства (тесты `tests/test_overlay.py`): картинка на каждый файл, копии
получают те же байты; архив побайтово одинаков между прогонами; таблица с
оверлеем и без совпадает; сбой отрисовки не трогает таблицу и пишется в
`overlay_errors.txt`. На обучающем наборе: 499 картинок, 0 ошибок, архив
53 МБ, прогон с оверлеем 27 с против 10 с без него (облачный CPU).
