# Спринт F1, 26 сентября: итог — no-go, в сервисе остаётся 1.0.0

Критерий записан до запуска (`PREREGISTRATION.md`, коммит 08ab013):
вложенный F1 по исследованиям ≥ 0.760 и по снимкам ≥ 0.598. Ни один вариант
его не прошёл: ни один не улучшил даже своё правило.

## Исходная точка (вложенная проверка 1.0.0)

- По снимкам F1 0.598 (TP 49 / FP 42 / FN 24). В ложных срабатываниях
  участвуют: ротация — 26, наклон оси — 12, артефакты — 5.
- По исследованиям F1 0.741 (TP 43 / FP 23 / FN 7). В ложных исследованиях:
  ротация — 12, наклон — 10, артефакты — 5.
- Потолки при идеальном правиле: ротация — 0.829 по снимкам и 0.826 по
  исследованиям; наклон — 0.636 и 0.766. Если бы наклон не срабатывал на
  снимках со сколиозом, было бы 0.611 и 0.768.
- 8 из 18 ложных срабатываний наклона — снимки, где эксперт отметил сколиоз.
  Все 14 таких снимков он считает нормой по оси.
- Ротация: AUC текущего признака 0.667. Модель на точках и оценках видимости
  малого вертела, поставленных врачом (80 снимков), даёт AUC 0.785 и F1 около
  0.60 в пересчёте на весь набор — это потолок подхода «по ориентирам».

## A. Наклон оси с учётом сколиоза

Вложенно, 99 снимков позвоночника; пороги подбираются по F1 наклона на
четырёх обучающих фолдах. Правило: наклон главной оси больше t1 и второй
признак проходит порог t2.

| вариант | F1 наклона (TP/FP/FN) | ложных на сколиозе |
|---|---|---|
| база: только угол главной оси | 0.353 (6/18/4) | 8 |
| A2: + квадратичный изгиб осевой линии | 0.345 (5/14/5) | 6 |
| A3: + СКО остатка от прямой | 0.357 (5/13/5) | 6 |
| A4: + разброс наклонов трёх третей | 0.323 (5/16/5) | 7 |
| A5: + наклон таза по гребням подвздошных костей | 0.276 (4/15/6) | 7 |

A1 — наклон таза отдельно. Первая версия поиска гребней показала AUC 0.85,
но только на 35 снимках, где гребни нашлись. Устойчивая версия находит их на
71–89 из 99 снимков и сигнала не даёт: AUC 0.48–0.55.

Признаки изгиба отделяют сколиоз от настоящего наклона слабо: AUC 0.54–0.68
среди снимков с углом больше 3°. Эксперт, по-видимому, опирается на то, чего
в геометрии маски нет.

## B. Ротация бедра v3

Логистическая регрессия с L2. Признаки в точке локализатора v2 берутся из
двойного кросс-фиттинга (`reports/rotation_localizer/double_crossfit_features.csv`),
к ним добавлены квадраты для U-образной связи. Регуляризация и порог
подбираются во внутренней проверке по фолдам обучающей части, решение
ставится на внешнем фолде.

| вариант | F1 ротации (TP/FP/FN) |
|---|---|
| сервис 1.0.0: профиль края v1, две границы | 0.476 (20/28/16) |
| B1: признаки в точке v2 | 0.471 (20/29/16) |
| B2: + признаки профиля v1 | 0.465 (23/40/13) |
| B3: + угол диафиза и геометрия маски | 0.471 (24/42/12) |
| B4: + признаки второго бедра исследования | 0.442 (23/45/13) |

Для справки, вне критерия: вариант напарника с ResNet18 на области вертела
даёт 0.626 по снимкам и 0.724 по исследованиям, то есть по исследованиям он
хуже сервиса (0.741).

## Вывод

На 100 исследованиях с метками одного эксперта оба главных источника ошибок
упираются в разметку, а не в метод. У ротации даже ориентиры, поставленные
врачом, дают F1 около 0.60. Наклон при сколиозе эксперт считает нормой, а по
изображению отличить такие снимки от косо уложенных не удаётся. Поднять F1
может только больше разметки: второй эксперт для оценки согласия, степень
ротации вместо метки «есть/нет», явная метка «сколиоз». Это план после
конкурса.
