# Спринт F1, 26 сентября: критерий включения (записан до запуска)

База — вложенная проверка `scripts/15_checkpoint_metrics.py`, версия 1.0.0:
F1 `quality_class` по снимкам 0.598 [0.51; 0.68] (249 снимков),
по исследованиям 0.741 (100 исследований).

## Что проверяем

**A. Наклон оси с учётом сколиоза.** 8 из 18 ложных срабатываний наклона
во вложенной проверке — снимки, где эксперт отметил сколиоз; среди верных
срабатываний таких нет. Новые признаки считаются по изображению (ось по
центрам позвонков, изгиб относительно хорды, наклон таза). Правило:
нарушение, если наклон больше t1 и признак изгиба не превышает t2. Пороги
подбираются по F1 наклона на четырёх обучающих фолдах и применяются к
пятому. Комментарии эксперта в правило и в подбор порогов не входят.

**B. Ротация бедра v3.** Логистическая регрессия с L2 на не более чем
шести признаках: профиль края v1, признаки в точке локализатора v2 (из
двойного кросс-фиттинга, `reports/rotation_localizer/`), угол диафиза,
заполненность маски; для U-образной связи — квадраты признаков.
Регуляризация и порог — на внутренних фолдах обучающей части, решение — на
внешнем фолде.

## Критерий включения

Конфигурация (A, B или A+B) идёт в сервис, только если одновременно:

1. вложенный F1 по исследованиям ≥ 0.760;
2. вложенный F1 по снимкам ≥ 0.598;
3. каждый включённый компонент по отдельности не снижает вложенный F1 по
   исследованиям.

Все испробованные варианты признаков записываются в отчёт спринта с
результатами, включая неудачные. Если ни одна конфигурация не проходит,
в сервисе остаётся версия 1.0.0.
