# Сборка презентации

`../DXA_QC_presentation.pptx` собирается скриптом на официальном шаблоне
ЛЦТ 2026 (архив «Презентация.zip» от организатора, в репозиторий не кладётся).

```bash
pip install python-pptx==1.0.2 Pillow
cp <путь к шаблону>.pptx presentation/src/template.pptx
cd presentation/src && python3 build.py ../DXA_QC_presentation.pptx
```

* Слайды 1–5 — обязательные слайды шаблона (в шаблоне 7–11): заполнены
  без изменения сетки, на слайде «Команда» удалены лишние карточки.
* Слайды 6–20 — решение по ТЗ, раздел 4; оформление — цвета, плашки
  заголовков и фоны шаблона.
* Шрифт — Montserrat из темы шаблона. Перед экспортом в PDF он должен быть
  установлен (Google Fonts, семейство Montserrat), иначе PowerPoint подставит
  другой шрифт и строки сдвинутся.

`assets/`: overlay текущей версии сервиса на снимках обучающего набора,
фрагменты `reports/errors/`, скриншот веб-интерфейса, `team_montage.png` —
три overlay для слайда «Описание команды», `avatar_*.png` — заглушки вместо
фото участников, `cdit_logo_hi.png` — логотип ЦДиТ, вырезанный с обложки ТЗ.
